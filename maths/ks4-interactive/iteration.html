Iteration Higher

Some equations, like x³ + 2x − 5 = 0, have no neat method for solving them. Iteration gets as close to the answer as you like by repeating one simple calculation over and over, each time feeding the answer back in. Your calculator's ANS key does all the hard work.

GCSE subject content (Higher): find approximate solutions to equations numerically using iteration; show a root lies in an interval by a change of sign; rearrange an equation into the form x = g(x)

Before you start. You'll need substitution with powers and roots (see Substitution), rearranging equations (Rearranging formulae), rounding to decimal places and bounds (Rounding and estimation), and the idea that a root of f(x) = 0 is where the graph y = f(x) crosses the x-axis (Recognising graphs). Subscripts label the steps: x₀ is the starting value, x₁ the next, and so on.

1 · Equations you can't solve exactly Higher

A quadratic can always be solved with the formula, but a cubic like x³ + 2x − 5 = 0 has no GCSE method. We can still see on a graph that it has a root (a solution) somewhere between 1 and 2. Drag the plum point along the x-axis: the value of f(x) is positive on one side of the root and negative on the other.

2 · A change of sign shows there's a root Higher

If f(a) and f(b) have opposite signs, the graph must cross the x-axis somewhere between a and b (as long as the graph is a continuous, unbroken curve). That proves there is a root in the interval. Repeating this with smaller and smaller steps (a decimal search) pins the root down one decimal place at a time.

Two warnings. (1) The curve must be unbroken: y = 1/x changes sign between −1 and 1 but never crosses the axis (it jumps at x = 0). (2) No change of sign doesn't mean no root: if the curve dips below the axis and comes back up between a and b, f(a) and f(b) have the same sign but there are two roots in between.

Exam phrasing: "f(1) = −2 < 0 and f(2) = 7 > 0. There is a change of sign, so there is a root between 1 and 2." State both values, their signs, and the conclusion.

3 · Rearranging f(x) = 0 into x = g(x) Higher

To iterate, first rearrange the equation so that x is on its own on one side: x = g(x). There are usually several ways to do this, and they all describe the same root: it's where the line y = x meets the curve y = g(x). Step through each rearrangement.

4 · The iterative formula, calculator-style Higher

Turn x = g(x) into an iterative formula xₙ₊₁ = g(xₙ): "the next value is g of this value". Start with a value x₀ near the root, put it in, get x₁, put that in, get x₂, and so on. On a calculator: type x₀ and press =; then type the formula using the ANS key for x and keep pressing =. Each press is one iteration.

5 · Seeing it: staircases and cobwebs Higher

Draw y = x and y = g(x). From x₀ go up to the curve (that height is g(x₀) = x₁), across to the line y = x (so the height becomes the new x), up or down to the curve again, and repeat. If the path closes in on the crossing point, the iteration converges. It makes a staircase when g slopes the same way as y = x, and a cobweb spiral when g slopes the other way. If g is steeper than y = x near the root (gradient bigger than 1 or less than −1), the path spirals or steps away: the iteration diverges.

6 · Giving the root to a required accuracy Higher

Keep iterating until the values stop changing at the accuracy you need: when two consecutive iterates round to the same value, that's your answer. For full marks, prove it with a change of sign at the bounds: to show the root is 1.33 to 2 d.p., show f(1.325) and f(1.335) have opposite signs, so the root lies between them and rounds to 1.33.

Worked examples

Show that x³ + 2x − 5 = 0 has a root between x = 1 and x = 2 Higher
Let f(x) = x³ + 2x − 5.
f(1) = 1 + 2 − 5 = −2 < 0. f(2) = 8 + 4 − 5 = 7 > 0.
Conclude: there is a change of sign (and f is continuous), so there is a root between 1 and 2.
Show that x³ + 2x − 5 = 0 can be rearranged to give x = ∛(5 − 2x) Higher
Subtract 2x and add 5: x³ = 5 − 2x.
Cube root both sides: x = ∛(5 − 2x), as required.
Using xₙ₊₁ = ∛(5 − 2xₙ) with x₀ = 1, find x₁, x₂ and x₃ to 4 d.p. Higher
x₁ = ∛(5 − 2 × 1) = ∛3 = 1.44224… = 1.4422
x₂ = ∛(5 − 2 × 1.44224…) = ∛2.11549… = 1.28372… = 1.2837
x₃ = ∛(5 − 2 × 1.28372…) = ∛2.43255… = 1.34489… = 1.3449
Tip: use ANS so the calculator keeps every digit. Typing in the rounded 1.4422 can change later digits.
Find the root of x³ + 2x − 5 = 0 to 2 d.p., and prove it Higher
Keep iterating: x₄ = 1.3220, x₅ = 1.3306, x₆ = 1.3274, x₇ = 1.3286, … The values settle at 1.328…, which rounds to 1.33.
Bounds: 1.33 to 2 d.p. means the root is between 1.325 and 1.335.
Change of sign: f(1.325) = −0.0238 < 0 and f(1.335) = 0.0493 > 0. So the root lies in that interval and is 1.33 (2 d.p.) ✓
What happens with xₙ₊₁ = (5 − xₙ³)/2 and x₀ = 1? Higher
Iterate: x₁ = 2, x₂ = −1.5, x₃ = 4.1875, x₄ = −34.21…
It diverges: the values get further from the root each time. Near x = 1.33 this g is much steeper than y = x, so each step overshoots by more. Use a different rearrangement.
Solve x² − 5x + 3 = 0 by iterating xₙ₊₁ = 5 − 3/xₙ from x₀ = 4, and check with the formula Higher
Iterate: 4 → 4.25 → 4.2941… → 4.3014… → 4.3025… → 4.3027… → 4.30277…
To 3 d.p.: x = 4.303.
Formula check: x = (5 + √13)/2 = 4.30277… ✓ (Iteration finds only one root at a time: the other root, 0.697, needs a different rearrangement.)

Quick check

What you've learned

  • If f(a) and f(b) have opposite signs and the graph is unbroken, there is a root between a and b. Quote both values and their signs.
  • Rearrange f(x) = 0 into x = g(x); the root is where y = x meets y = g(x). There are usually several possible rearrangements.
  • The iterative formula xₙ₊₁ = g(xₙ) is repeated from a starting value x₀. Use the calculator's ANS key so no accuracy is lost.
  • The iteration converges (staircase or cobweb closing in) when g is less steep than y = x near the root; otherwise it diverges and you need another rearrangement.
  • Stop when consecutive iterates agree to the required accuracy, then prove it with a change of sign at the bounds (e.g. 1.325 and 1.335 for 1.33).
