Computer science and maths resources, all in one place

Computing Hub is a growing collection of free classroom tools built by a practising teacher: revision games, diagnostic questions, programming activities, block-based builders and club projects.

Everything runs in the browser, works on a phone, and needs no login.

How this site works

Each project is a separate repository in the Computing-Hub organisation and is published as a folder of this site, so links are short and stable. This page is the front door.

Everything here is free to use in the classroom. Teaching notes, answers and editable versions for member schools are coming later.
